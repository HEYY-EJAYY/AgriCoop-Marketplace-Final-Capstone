## Dependency audit summary

The baseline package includes the following likely migration blockers or template remnants:

- `vite-plugin-manus-runtime` — direct Manus-specific dependency.
- `@aws-sdk/client-s3` and `@aws-sdk/s3-request-presigner` — current storage path; target is Supabase Storage.
- `express`, `@trpc/server`, `@trpc/client`, `@trpc/react-query`, `drizzle-orm`, and `mysql2` — current runtime stack; target is Next.js App Router plus Supabase Postgres.
- `wouter` and `vite` — current client/runtime routing/build stack; target is Next.js App Router.

This audit intentionally does not claim that all listed packages are unused. Removal belongs to later migration slices with tests after each change.
