If an authorized diagnostic reports `application_user_lookup`, the first query is the Drizzle equivalent of:

```sql
SELECT <all agricoop_app.users columns>
FROM "agricoop_app"."users"
WHERE "agricoop_app"."users"."openId" = $1
LIMIT $2;
```

The parameter is the UUID returned by successful Supabase Auth validation. The mixed-case identifier is quoted. The separate `canonical_role_lookup` query runs only after this first query succeeds.
